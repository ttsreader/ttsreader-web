복사
이게 무엇이고, 언제 쓰면 좋을까요?

내보내기는 열려 있는 문서를 실제 mp3 파일로 만들어 보관할 수 있게 합니다. 브라우저 밖에서 듣고 싶을 때 — 휴대폰, 차 안, 오프라인, 팟캐스트 앱 — 또는 게시하거나 다른 사람에게 전달하려고 오디오 자체가 필요할 때 사용하세요. 여기서 읽기만 한다면 재생을 누르면 되고, 추가 소모는 없습니다.

  • 내보내기 전 반드시 재생하여 원하는 대로 들리는지 확인하세요. 완벽하게 편집 후 내보내기.
  • 프리미엄 음성(목소리 갤러리에서 별 표시된 것)만 지원합니다.
  • 프리미엄 문자 할당량 또는 크레딧에서 문자를 소비합니다.

귀하의 API 키

API 액세스에는 Premium 구독이 필요합니다

API 키를 생성하고 강력한 TTS API 사용을 시작하려면 Premium으로 업그레이드하세요.

코드 예제

CURL 예제

curl -X POST "https://ttsreader.com/api/ttsSync" \
-H "Authorization: Bearer UAPI-YOUR_SECRET_KEY" \
-H "Content-Type: application/json" \
--data '{"text": "Hello world, this is a test from TTSReader API.","lang": "en-US", "voice": "Nova Premium", "rate":1, "quality": "48khz_192kbps" }' \
--output "hello.mp3"

JavaScript 예제

async function generateTTS() {
    const response = await fetch('https://ttsreader.com/api/ttsSync', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer UAPI-YOUR_SECRET_KEY',
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            text: "Hello world, this is a test from TTSReader API.",
            lang: "en-US",
            voice: "Nova Premium",
            quality: "48khz_192kbps",
            rate: 1
        })
    });

    if (response.ok) {
        const audioBlob = await response.blob();
        const url = URL.createObjectURL(audioBlob);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'hello.mp3';
        a.click();
    }
}

요청 매개변수

  • text (필수): 음성으로 변환할 텍스트
  • lang (필수): 언어 코드 (예: 'ko-KR', 'en-US')
  • voice (필수): 음성 이름 - TTSReader 플레이어의 음성 또는 Azure 음성 사용 Azure 음성 갤러리
  • rate (선택사항): 음성 속도 (0.5~2.0, 기본값: 1.0)
  • quality (선택사항): "48khz_192kbps" 또는 비워두기 (기본값 24kHz)


중요 참고 사항

  • 문자 수를 수천 자 이내로 제한하세요 (정확한 한도는 알 수 없지만 5,000자는 안전합니다). 이것은 동기식 API이며 5분 후 타임아웃됩니다. 5분 안에 MP3를 생성할 수 있으면 성공하지만, 그렇지 않으면 타임아웃됩니다. 단, AI가 시작되면 크레딧이 소비됩니다.
  • 장문 텍스트 및 단일 파일 내 다중 음성을 지원하는 비동기 API가 곧 출시됩니다.
  • ttsSync 엔드포인트는 텍스트 내 음성 세터 ({{set: voice, language, rate}})를 지원하지 않습니다. API 요청에서 단일 음성을 설정하세요.
  • 음성 이름은 음성 선택기 UI에 표시된 대로입니다. 또한 Azure의 모든 뉴럴 AI 음성이 지원됩니다. https://speech.azure.cn/portal/voicegallery에서 Azure 음성 갤러리를 방문하여 음성을 선택하세요.
  • 기타 필요한 사항이나 피드백, 제안이 있으시면 contact@ttsreader.com으로 알려주세요
