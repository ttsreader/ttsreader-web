Comment Fonctionne la Prononciation

Apprenez comment fonctionne le dictionnaire de prononciation

** Expérimental, à utiliser avec précaution

La fonction de prononciation remplace vos termes originaux dans le texte par leurs termes de prononciation respectifs (lire comme...), juste avant que le texte ne soit envoyé au moteur de synthèse vocale. Elle suit ces règles :

  • Trouve uniquement les mots entiers
  • Sensible à la casse — 'Hi' ≠ 'hi'
  • Remplacements sélectifs — pour ne remplacer que certaines occurrences d'un terme, utilisez simplement une casse différente pour les occurrences à remplacer
  • Testez la prononciation avec le petit bouton de lecture dans le champ de saisie de texte avant d'ajouter
  • Le bouton 'Trouver et Surligner' marquera les mots trouvés dans la zone de texte principale
  • Utilisez la case à cocher pour chaque élément du dictionnaire pour le désactiver tout en le conservant dans le dictionnaire
  • Vous pouvez utiliser des formes phonétiques pour la prononciation, ce n'est pas obligatoirement un vrai mot, tant qu'il est lu comme vous le souhaitez

Qu'est-ce que c'est, et quand l'utiliser ?

L'export transforme le document ouvert en un vrai fichier mp3 que vous gardez. Utilisez-le pour écouter hors du navigateur — au téléphone, en voiture, hors ligne ou dans une application de podcast — ou quand vous avez besoin de l'audio lui-même, pour le publier ou le transmettre. Pour simplement lire ici, appuyez sur lecture : cela ne coûte rien de plus.

  • Merci de LIRE avant d'exporter – pour vous assurer que tout sonne exactement comme vous le souhaitez. Éditez à la perfection. Puis exportez quand vous êtes prêt.
  • Fonctionne uniquement avec les voix premium (marquées d'une étoile dans la galerie).
  • Il consomme des caractères de votre quota de caractères premium ou crédits.
  • Nouveau : {{pause}} et {{pause:DURATION_IN_MS}} sont supportés. Assurez-vous qu'ils sont formatés SANS espaces dans les accolades {{...}}
  • Vous pouvez également créer votre chaîne de podcast personnelle pour écouter vos exportations en déplacement avec votre application de podcast préférée.
  • Besoin d'un format audio spécifique ? Utilisez notre simple convertisseur MP3 en WAV.

Votre Clé API

L'accès à l'API nécessite un abonnement Premium

Passez à Premium pour générer votre clé API et commencer à utiliser notre puissante API TTS.

Exemples de Code

Exemple CURL

curl -X POST "https://ttsreader.com/api/ttsSync" \
-H "Authorization: Bearer UAPI-YOUR_SECRET_KEY" \
-H "Content-Type: application/json" \
--data '{"text": "Hello world, this is a test from TTSReader API.","lang": "en-US", "voice": "Nova Premium", "rate":1, "quality": "48khz_192kbps" }' \
--output "hello.mp3"

Exemple JavaScript

async function generateTTS() {
    const response = await fetch('https://ttsreader.com/api/ttsSync', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer UAPI-YOUR_SECRET_KEY',
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            text: "Hello world, this is a test from TTSReader API.",
            lang: "en-US",
            voice: "Nova Premium",
            quality: "48khz_192kbps",
            rate: 1
        })
    });

    if (response.ok) {
        const audioBlob = await response.blob();
        const url = URL.createObjectURL(audioBlob);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'hello.mp3';
        a.click();
    }
}

Paramètres de Requête

  • text (requis) : Le texte à convertir en parole
  • lang (requis) : Code de langue (ex., 'en-US', 'fr-FR')
  • voice (requis) : Nom de la voix - utilisez les voix du Lecteur TTSReader ou toute voix Azure de Galerie de Voix Azure
  • rate (optionnel) : Vitesse de parole (0.5 à 2.0, par défaut : 1.0)
  • quality (optionnel) : "48khz_192kbps" ou vide (par défaut 24kHz)


Notes Importantes

  • Limitez les caractères à quelques milliers (la limite exacte est inconnue, mais 5k caractères est sûr), car il s'agit d'une API synchrone qui expire après 5 minutes. Si elle peut générer le MP3 en 5 minutes, elle le fera ; sinon, elle expirera avant que le MP3 ne soit prêt, mais comme l'IA est déjà lancée, elle consommera des crédits.
  • L'API asynchrone sera bientôt disponible pour les textes longs et pour supporter plusieurs voix dans un seul fichier.
  • Le point de terminaison ttsSync ne supporte pas les configurateurs de voix (c.-à-d. : {{set: voice, language, rate}}) dans le texte. Donc, une seule voix définie dans la requête API.
  • Le nom de la voix est celui affiché dans l'interface du sélecteur de voix. De plus, TOUTES les voix neuronales IA d'Azure sont prises en charge. Vous pouvez aller dans la galerie de voix d'Azure à https://speech.azure.cn/portal/voicegallery et sélectionner une voix.
  • Si vous avez besoin d'autre chose, ou avez des commentaires, suggestions, veuillez nous contacter à contact@ttsreader.com
