    Como a Pronúncia Funciona

    Saiba como o dicionário de pronúncia funciona

    ** Experimental, use com cautela

    A função de pronúncia substitui seus termos originais no texto pelos respectivos termos de pronúncia (ler como...), logo antes do texto ser enviado ao motor de síntese de voz. Segue estas regras:

    • Encontra apenas palavras inteiras
    • Sensível a maiúsculas — 'Hi' ≠ 'hi'
    • Substituições seletivas — para substituir apenas algumas ocorrências de um termo, simplesmente use uma caixa diferente para as ocorrências que devem ser substituídas
    • Teste a pronúncia com o pequeno botão de reprodução no campo de entrada de texto antes de adicionar
    • O botão 'Encontrar e Destacar' marcará as palavras encontradas na área de texto principal
    • Use a caixa de seleção para cada item do dicionário para desativá-lo, mas mantê-lo no dicionário
    • Você pode usar formas fonéticas para pronúncia, não precisa ser uma palavra real, desde que seja lida da forma que você precisa

    Sua Chave API

    Acesso à API requer assinatura Premium

    Atualize para Premium para gerar sua chave API e começar a usar nossa poderosa API TTS.

    Exemplos de Código

    Exemplo CURL

    curl -X POST "https://ttsreader.com/api/ttsSync" \
-H "Authorization: Bearer UAPI-YOUR_SECRET_KEY" \
-H "Content-Type: application/json" \
--data '{"text": "Hello world, this is a test from TTSReader API.","lang": "en-US", "voice": "Nova Premium", "rate":1, "quality": "48khz_192kbps" }' \
--output "hello.mp3"

    Exemplo JavaScript

    async function generateTTS() {
    const response = await fetch('https://ttsreader.com/api/ttsSync', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer UAPI-YOUR_SECRET_KEY',
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            text: "Hello world, this is a test from TTSReader API.",
            lang: "en-US",
            voice: "Nova Premium",
            quality: "48khz_192kbps",
            rate: 1
        })
    });

    if (response.ok) {
        const audioBlob = await response.blob();
        const url = URL.createObjectURL(audioBlob);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'hello.mp3';
        a.click();
    }
}

    Parâmetros da Requisição

    • text (obrigatório): O texto a ser convertido em fala
    • lang (obrigatório): Código do idioma (ex. 'pt-BR', 'en-US')
    • voice (obrigatório): Nome da voz - use vozes do Player TTSReader ou qualquer voz Azure de Galeria de Vozes Azure
    • rate (opcional): Velocidade da fala (0.5 a 2.0, padrão: 1.0)
    • quality (opcional): "48khz_192kbps" ou vazio (padrão 24kHz)


    Notas Importantes

    • Limite os caracteres a alguns milhares (o limite exato é desconhecido, mas 5k caracteres é seguro), pois esta é uma API síncrona que expira após 5 minutos. Se conseguir gerar o MP3 em 5 minutos, fará; caso contrário, expirará antes do MP3 estar pronto, mas como a IA já foi iniciada, consumirá créditos.
    • A API assíncrona estará disponível em breve para textos longos e para suportar múltiplas vozes em um único arquivo.
    • O endpoint ttsSync não suporta configuradores de voz (ou seja: {{set: voice, language, rate}}) no texto. Portanto, uma única voz definida na requisição da API.
    • O nome da voz é o mostrado na interface do seletor de vozes. Além disso, TODAS as vozes neurais de IA do Azure são suportadas. Você pode ir à galeria de vozes do Azure em https://speech.azure.cn/portal/voicegallery e selecionar uma voz de lá.
    • Se precisar de algo mais, ou tiver comentários, sugestões, entre em contato conosco em contact@ttsreader.com
