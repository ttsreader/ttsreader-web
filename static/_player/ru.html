    Как работает произношение

    Узнайте, как работает словарь произношений

    ** Экспериментальная функция, используйте с осторожностью

    Функция произношения заменяет ваши исходные термины в тексте на соответствующие термины произношения (читать как...) непосредственно перед отправкой текста в движок синтеза речи. Она следует этим правилам:

    • Находит только целые слова
    • Чувствительно к регистру — 'Hi' ≠ 'hi'
    • Выборочные замены — чтобы заменить только некоторые вхождения термина, просто используйте другой регистр для вхождений, которые нужно заменить
    • Проверьте произношение с помощью маленькой кнопки воспроизведения в поле ввода текста перед добавлением
    • Кнопка "Найти и выделить" отметит слова, найденные в основном текстовом поле
    • Используйте флажок для каждого элемента в словаре, чтобы отключить его, но сохранить в словаре
    • Вы можете использовать фонетические формы для произношения, это не обязательно должны быть настоящие слова — главное, чтобы они читались так, как вам нужно

    Доступ к API требует Premium подписку

    Обновитесь до Premium, чтобы сгенерировать ваш API ключ и начать использовать наш мощный TTS API.

    Примеры кода

    Пример CURL

    curl -X POST "https://ttsreader.com/api/ttsSync" \
-H "Authorization: Bearer UAPI-YOUR_SECRET_KEY" \
-H "Content-Type: application/json" \
--data '{"text": "Hello world, this is a test from TTSReader API.","lang": "en-US", "voice": "Nova Premium", "rate":1, "quality": "48khz_192kbps" }' \
--output "hello.mp3"

    Пример JavaScript

    async function generateTTS() {
    const response = await fetch('https://ttsreader.com/api/ttsSync', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer UAPI-YOUR_SECRET_KEY',
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            text: "Hello world, this is a test from TTSReader API.",
            lang: "en-US",
            voice: "Nova Premium",
            quality: "48khz_192kbps",
            rate: 1
        })
    });

    if (response.ok) {
        const audioBlob = await response.blob();
        const url = URL.createObjectURL(audioBlob);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'hello.mp3';
        a.click();
    }
}

    Параметры запроса

    • text (обязательно): Текст для преобразования в речь
    • lang (обязательно): Код языка (например, 'ru-RU', 'en-US')
    • voice (обязательно): Название голоса - используйте голоса из TTSReader Player или любой голос Azure из Галерея голосов Azure
    • rate (опционально): Скорость речи (от 0.5 до 2.0, по умолчанию: 1.0)
    • quality (необязательно): "48khz_192kbps" или пусто (по умолчанию 24kHz)


    Важные замечания

    • Ограничьте количество символов несколькими тысячами (точный лимит неизвестен, но 5 тыс. символов безопасно), так как это синхронный API с таймаутом 5 минут. Если MP3 может быть сгенерирован за 5 минут — будет, иначе произойдёт таймаут до готовности MP3, но поскольку ИИ уже запущен — кредиты будут списаны.
    • Асинхронный API для длинных текстов и поддержки нескольких голосов в одном файле скоро появится.
    • Эндпоинт ttsSync не поддерживает голосовые сеттеры (т.е. {{set: voice, language, rate}}) внутри текста. Только один голос — задаётся в запросе API.
    • Название голоса — как показано в интерфейсе выбора голоса. Кроме того, поддерживаются ВСЕ нейронные ИИ-голоса Azure. Вы можете перейти в галерею голосов Azure по адресу https://speech.azure.cn/portal/voicegallery и выбрать голос оттуда.
    • Если вам нужно что-то ещё, или есть отзывы, предложения — сообщите нам по адресу contact@ttsreader.com
