How Pronunciation Works

Learn how the pronunciation dictionary works

** Experimental, use with caution

The pronunciation function replaces your original terms in the text with their respective pronunciation (read as...) terms, right before the text is sent to the speech synthesis engine. It follows these rules:

  • Finds whole words only
  • Case sensitive — 'Hi' ≠ 'hi'
  • Selective replacements — to replace only some appearances of a term simply use a different case for appearances that should be replaced
  • Test pronunciation with the small play button in the text-input field before adding
  • The 'Find & Highlight' button will mark the words found in the main text area
  • Use the checkbox for each item in the dictionary to disable it but still keep it in the dictionary
  • You can use phonetic forms for pronunciation, it doesn't have to be a real words - as long as it is read the way you need it to

What is this, and when to use it?

An export turns the document you have open into a real mp3 file you keep. Use it when you want to listen away from the browser — on a phone, in the car, offline, or in a podcast app — or when you need the audio itself, to publish or to hand to someone. For simply reading along here, just press play: that costs nothing extra.

  • Please PLAY before export - to make sure it ALL sounds exactly as you like it to. Edit to perfection. Then export when ready.
  • Supports premium voices only.
  • It consumes characters from your premium-characters quota or credits.
  • {{pause}} And {{pause:DURATION_IN_MS}} are supported - just make sure they are formatted WITHOUT any white space inside the double-braces {{...}}
  • You can also create your personal podcast channel to listen to your exports on the go with your favorite podcast app.
  • Need a specific audio format? Use our simple MP3 to WAV converter.

Code Examples

CURL Example

curl -X POST "https://ttsreader.com/api/ttsSync" \
-H "Authorization: Bearer UAPI-YOUR_SECRET_KEY" \
-H "Content-Type: application/json" \
--data '{"text": "Hello world, this is a test from TTSReader API.","lang": "en-US", "voice": "Nova Premium", "rate":1, "quality": "48khz_192kbps" }' \
--output "hello.mp3"

JavaScript Example

async function generateTTS() {
    const response = await fetch('https://ttsreader.com/api/ttsSync', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer UAPI-YOUR_SECRET_KEY',
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            text: "Hello world, this is a test from TTSReader API.",
            lang: "en-US",
            voice: "Nova Premium",
            quality: "48khz_192kbps",
            rate: 1
        })
    });

    if (response.ok) {
        const audioBlob = await response.blob();
        const url = URL.createObjectURL(audioBlob);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'hello.mp3';
        a.click();
    }
}

Request Parameters

  • text (required): The text to convert to speech
  • lang (required): Language code (e.g., 'en-US', 'es-ES')
  • voice (required): Voice name - use voices from TTSReader Player or any Azure voice from Azure Voice Gallery
  • rate (optional): Speech rate (0.5 to 2.0, default: 1.0)
  • quality (optional): "48khz_192kbps" or empty (which defaults to 24kHz)


Important Notes

  • Limit charcters to a few thousands (exact limit is unknown, but 5k characters is safe), as this is synchronous API, tjat times out after 5 minutes. So, if it can generate the MP3 within 5 minutes it will - otherwise it will time out before MP3 is ready - but since the AI is started - it will consume credits.
  • Async API is coming soon for long-texts, and for supporting multiple voices in a single file.
  • The ttsSync endpoint does not support voice-setters (ie: {{set: voice, language, rate}}) within the text. So, a single voice - set in the API request.
  • The name of the voice is as shown in the voice-selector UI. In addition ALL Azure's Neural AI voices are supported. So, you're welcome to go to Azure's voice gallery at https://speech.azure.cn/portal/voicegallery and select a voice from there.
  • If you need anything else, or have feedback, suggestions, please let us know at contact@ttsreader.com
