    Hoe uitspraak werkt

    Leer hoe het uitspraakwoordenboek werkt

    ** Experimenteel, gebruik met voorzichtigheid

    De uitspraakfunctie vervangt uw oorspronkelijke termen in de tekst door hun respectieve uitspraak (lees het als...) termen, vlak voordat de tekst naar de spraaksynthese-engine wordt gestuurd. Het volgt deze regels:

    • Vindt alleen hele woorden
    • Hoofdlettergevoelig — 'Hi' ≠ 'hi'
    • Selectieve vervangingen — om slechts enkele verschijningen van een term te vervangen, gebruik een andere hoofdletterinstelling voor de verschijningen die vervangen moeten worden
    • Test de uitspraak met de kleine afspeelknop in het tekstinvoerveld voordat u toevoegt
    • De knop 'Zoeken en markeren' zal de gevonden woorden in het hoofdtekstveld markeren
    • Gebruik het selectievakje voor elk item in het woordenboek om het uit te schakelen maar toch in het woordenboek te bewaren
    • U kunt fonetische vormen gebruiken voor uitspraak, het hoeft geen echt woord te zijn - zolang het wordt gelezen zoals u het nodig heeft

    Uw API-sleutel

    API-toegang vereist Premium-abonnement

    Upgrade naar Premium om uw API-sleutel te genereren en onze krachtige TTS API te gaan gebruiken.

    Codevoorbeelden

    CURL-voorbeeld

    curl -X POST "https://ttsreader.com/api/ttsSync" \
-H "Authorization: Bearer UAPI-YOUR_SECRET_KEY" \
-H "Content-Type: application/json" \
--data '{"text": "Hello world, this is a test from TTSReader API.","lang": "en-US", "voice": "Nova Premium", "rate":1, "quality": "48khz_192kbps" }' \
--output "hello.mp3"

    JavaScript-voorbeeld

    async function generateTTS() {
    const response = await fetch('https://ttsreader.com/api/ttsSync', {
        method: 'POST',
        headers: {
            'Authorization': 'Bearer UAPI-YOUR_SECRET_KEY',
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            text: "Hello world, this is a test from TTSReader API.",
            lang: "en-US",
            voice: "Nova Premium",
            quality: "48khz_192kbps",
            rate: 1
        })
    });

    if (response.ok) {
        const audioBlob = await response.blob();
        const url = URL.createObjectURL(audioBlob);
        const a = document.createElement('a');
        a.href = url;
        a.download = 'hello.mp3';
        a.click();
    }
}

    Verzoekparameters

    • text (vereist): De tekst om naar spraak te converteren
    • lang (vereist): Taalcode (bijv. 'nl-NL', 'en-US')
    • voice (vereist): Stemnaam - gebruik stemmen van TTSReader Player of elke Azure-stem van Azure Stemmengalerij
    • rate (optioneel): Spraaksnelheid (0.5 tot 2.0, standaard: 1.0)
    • quality (optioneel): "48khz_192kbps" of leeg (standaard 24kHz)


    Belangrijke opmerkingen

    • Beperk het aantal karakters tot enkele duizenden (exacte limiet is onbekend, maar 5k karakters is veilig), aangezien dit een synchrone API is die na 5 minuten een timeout krijgt. Als de MP3 binnen 5 minuten kan worden gegenereerd, dan lukt het - anders treedt er een timeout op voordat de MP3 klaar is - maar omdat de AI al is gestart, worden er credits verbruikt.
    • Asynchrone API komt binnenkort voor lange teksten en voor ondersteuning van meerdere stemmen in een enkel bestand.
    • Het ttsSync-eindpunt ondersteunt geen voice-setters (bijv. {{set: voice, language, rate}}) in de tekst. Dus een enkele stem - ingesteld in het API-verzoek.
    • De naam van de stem is zoals weergegeven in de stemselector-UI. Bovendien worden ALLE neurale AI-stemmen van Azure ondersteund. U kunt naar Azure's stemmengalerij gaan op https://speech.azure.cn/portal/voicegallery en daar een stem selecteren.
    • Als u iets anders nodig heeft, of feedback of suggesties heeft, laat het ons weten via contact@ttsreader.com
